# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately via **GitHub Security Advisories**:

1. Go to the repository on GitHub.
2. Click the **Security** tab.
3. Click **Report a vulnerability** (a.k.a. private vulnerability reporting / Security Advisory).

This keeps the details private until a fix is available.

## What to Include

- Affected version(s) / commit.
- Description of the vulnerability and its impact.
- Steps to reproduce (minimal config, request, and observed vs. expected behavior).
- Any suggested fix or mitigation, if known.

## Response

We will acknowledge receipt, assess the report, and coordinate a fix and disclosure timeline with you. Thank you for reporting responsibly.
